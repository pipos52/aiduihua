# NovelChat - 小说文风聊天

在安卓手机本地训练对话模型的聊天应用。导入 TXT 小说后，应用会学习小说的行文风格与对话模式，并模仿该风格与你对话。

**适配设备**：红米 K40 游戏增强版（天玑 1200，Android 11+）

## ⚡ 手机端 3 步获取 APK

你不需要电脑。按下面步骤走：

### 第 1 步：在 GitHub 建空仓库

1. 手机上打开 **GitHub App**（没有的话去应用商店装一个），登录你的账号
2. 点底部 `+` → `New repository`
3. Repository name：填 `NovelChat`（随便，能认就行）
4. Public / Private 随意 → 点 `Create repository`
5. 创建后你会看到 `Quick setup` 页面，**把这个页面保持不动**（下一步要用）

### 第 2 步：上传代码

**方式 A（推荐，用 GitHub App 直接传 NovleChat 文件夹 zip）**：
1. 把 `NovelChat.zip`（我提供的）保存到手机
2. 解压后得到 `NovelChat/` 文件夹
3. GitHub App 打开你刚建的仓库 → 右上角 `···` → `Add file` → `Upload files`
4. 选择解压后 `NovelChat/` 目录里 **所有文件和子目录**（整个根目录一起上传）
5. 底部 `Commit changes` → `Commit`

**方式 B（网页也可以）**：
同上，用手机浏览器打开 GitHub，步骤一样。

### 第 3 步：等 Actions 自动构建 APK，下载安装

1. 仓库页面顶部有 `Actions` 标签 → 点进去
2. 左侧会看到 `Build Debug APK` 这个 workflow，右侧会有一个橙色转圈的 `Build`
3. **等 3~6 分钟**（首次比较慢），等它变成绿色 ✔️
4. 点进去这个成功的 build → 页面最底部 `Artifacts` 区域有 `novelchat-debug-apk`
5. 点它下载 zip，**解压后得到 `app-debug.apk`**
6. 点 APK 文件安装到红米 K40（首次安装可能要在系统设置里允许"未知来源"）

## 🚀 使用 App

1. **打开应用** → 进入角色列表
2. **右下角 +** → 创建角色（填名称，阶数选 3 推荐）
3. **点角色右侧 ⋮** → `继续训练（导入TXT）` → 选你的小说文件
4. 等几秒（百万字约 5-10 秒）→ 训练完成
5. **想再导入一本？** 重复第 3 步就行，多本小说增量合并到同一角色
6. **点角色名** → 进入聊天 → 开始对话
7. 角色会自动学习你的问法和对话，下次打开直接继续聊

## 🧠 功能亮点

| 功能 | 说明 |
|------|------|
| 多角色独立 | 每个角色模型、记忆完全隔离，互不影响 |
| 多本 TXT 合并 | 一个角色可以导入多部作品，文风融合 |
| 本地端训练 | 纯 Markov 链 + 内存哈希表，无 GPU，秒级完成 |
| 深度对话 | 5 层策略：问答记忆→上下文→主题召回→多候选打分→风格包装 |
| 对话学习 | 每次"问+答"自动回灌训练，角色越聊越懂你 |
| 持久记忆 | 对话历史与模型自动存手机，重启不丢 |

## 🔧 模型阶数怎么选

| 阶数 | 特点 | 建议 |
|------|------|------|
| 1 | 非常随机，想象力高 | 想要意外的回答 |
| 2 | 平衡 | 一般 |
| **3** | **最贴近原文风格** | **推荐** |
| 4 | 非常贴原文，可能死板 | 训练文本 >100 万字时 |
